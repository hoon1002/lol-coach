**판정: "스킬샷은 대개 미니언 어그로를 부르지 않는다" → 조건부로 맞다.**
- 미니언의 지원 요청은 평타와 **대상 지정 스킬 대부분**에서 생기고, 그 밖의 스킬은 **소수만** 해당한다. 그래서 방향·위치를 겨누는 스킬샷은 **대부분** 미니언 어그로를 부르지 않는다. 다만 예외 스킬이 있고(스킬별 표시), 위키 본문은 '스킬샷'이라는 말을 직접 쓰지 않는다. 이 판정은 "대상 지정이 아닌 스킬 = 스킬샷"으로 읽은 조사원 해석이다.
- **포탑은 다르다.** 포탑 근처에서는 스킬샷이든 평타든 **피해만 주면** 포탑이 나를 노린다. 따라서 "스킬샷은 안전하다"를 포탑 근처까지 넓혀 쓰면 틀린다.
- 쉬운 말 한 줄: **"평타나 찍어 쓰는 스킬로 상대를 치면 근처 적 미니언이 나를 노린다. 날려 쓰는 스킬은 대개 괜찮다. 하지만 상대 포탑 근처에서는 무엇으로 치든 포탑이 나를 노린다."**
- 퀴즈 Q1 정답 문장 제안: "스킬샷은 **대개** 미니언 어그로를 부르지 않는다(예외 스킬 있음). 포탑 어그로는 스킬샷에도 생긴다."

## 8. 상성(카운터)

**한 줄로**: 상성은 "어떤 챔피언이나 분류가 다른 쪽을 상대로 유리한 관계"다. Riot은 클래스를 서로 물고 물리는 관계로 설계했다. 예를 들어 **탱커는 한 번에 몰아치는 피해(암살자·마법사)에는 강하고, 꾸준히 때리는 피해(전사·원거리 딜러)에는 약하다.** 그래서 모든 분류를 이기는 분류는 없다. 챔피언 하나하나의 상성은 스킬 구조와 패치에 따라 달라진다.

## 10. 콘텐츠 앱(가이드·교과서형)에 적용되는 Riot 정책

**한 줄로**: Riot 데이터를 쓰지 않는 순수 콘텐츠 앱은 **팬 콘텐츠 정책**을 따른다. 이 정책은 **비상업**이 원칙이라 유료 구독(페이월)과 앱스토어 출시에는 Riot의 **서면 라이선스** 또는 그 프로젝트용 **유효한 Riot API 키**가 필요하다. API 키를 받은 등록 제품이 되면 **개발자 정책**이 적용되어 무료 등급을 두고 '변형적' 유료 콘텐츠를 팔 수 있다. 챔피언 그림 같은 Riot 자산은 그 범위 안에서만 쓴다.

| 규칙 | 팬 콘텐츠 정책 ('Legal Jibber Jabber', 최종 갱신 2018-08) | 개발자 정책 (등록 제품, 최종 갱신 2025-05-29) |
|---|---|---|
| 상업화 | **비상업 원칙**. 크라우드펀딩, 사업체가 운영하는 프로젝트, **페이월 콘텐츠**는 서면 라이선스 필요 | 상태가 **Approved 또는 Acknowledged**일 때만 수익화. **무료 등급 필수**(광고 가능) |
| 예외 | ① 개인의 적절한 광고 수익 ② 방송 중 구독·후원 ③ **API 약관을 지키고 그 프로젝트용 유효한 API 키를 가진 상업 프로젝트**(키가 취소되면 즉시 중단) | 유료 콘텐츠는 **변형적**이어야 함(새 정보·통찰 추가). 구독·후원·크라우드펀딩 허용, 도박·착취형 과금·블록체인 금지 |
| Riot IP·그림 | 원본성 요구. **"게임과 앱에서 우리 IP 사용을 금지"**한다고 적고, 캐릭터 외형·스킬·맵·아이콘·아이템을 IP로 든다 | 승인 자산: **Data Dragon, Press Kit** 등. 로고·상표는 핵심 가치에 불가피할 때만. Riot 게임·제품과 스타일·기능이 비슷하면 안 됨 |
| 상표·이름 | Riot 로고·상표는 서면 라이선스 없이 금지. **도메인·SNS 계정·검색 키워드**에도 쓰지 말 것 | 위와 같은 취지 |
| 앱스토어 | 애플·구글 스토어 출시는 **서면 라이선스 또는 유효한 API 키** 필요 | 등록 제품은 가능(API 약관 준수) |
| 고지 | 눈에 띄는 곳에 "Riot Games가 보증·후원하지 않음" 취지 고지 | Core Policies의 법적 고지 문구를 잘 보이는 곳에(research.md B-6) |

- 출처: [공식] https://www.riotgames.com/en/legal (확인일 2026-11-04) · https://developer.riotgames.com/policies/general (확인일 2026-11-04)
- **설계 함의** `[조사원 해석, 법률 자문 아님]`: 한 판 분석을 뒤로 미뤄도 **Riot 개발자 포털에 제품을 등록하고 API 키를 받는 경로가 필요하다.** 그래야 ① 유료 등급 ② 앱스토어 출시 ③ Data Dragon 그림(챔피언 초상·아이콘·아이템) 사용이 정책상 자리를 잡는다. 순수 팬 콘텐츠로 남으면 무료·비상업이 원칙이고, 앱 안 챔피언 그림 사용도 막힐 수 있다. 등록 시 '변형적 가치'는 교과서 해설·도해·드릴이다. 최종 판단은 Riot DevRel 확인과 변호사 검토가 필요하다(research.md H장·I장).
- **2026 정책 변화 재확인**: ① 2026-10-06부터 미등록 앱의 게임 메모리 접근 차단 ② 26.21부터 리플레이 다운로드 시간당 10회. 둘 다 **콘텐츠 앱에는 직접 영향이 거의 없다**(분석 기능을 다시 열 때 영향). 두 정책 문서 자체의 2026년 개정은 찾지 못했다(팬 콘텐츠 정책 2018-08, 개발자 정책 2025-05-29 표기). [공식] https://support.riotgames.com/en-us/riot/performance/game-memory-access-removed-for-third-party-apps , 26.21 노트
- 프로 경기 영상은 팬 콘텐츠 정책상 원본성 요구에 걸린다. e스포츠 VOD를 가벼운 해설만 붙여 쓰지 말고, 데이터로 다시 그린 도해를 쓴다(research.md C-7).
