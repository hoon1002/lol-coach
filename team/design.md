## 0. 한 줄 방향

**코치가 작전판 위에 자석을 놓고, 형광펜으로 그 순간 하나만 칠해 준다.**

- 화면마다 주인공은 작전판 하나다. 글은 그 판을 읽게 돕는 한 줄씩만 둔다.
- 노랑은 두 곳에만 쓴다. 판 위 '그 순간' 원 하나와 오답 띠다.
- 숫자는 '자세히 보기' 시트 한 겹 안에만 둔다. 화면 본문에는 눈에 보이는 신호(회색 아이콘, 평타 원, 체력바, 미니언 몇 마리 값)만 쓴다.

## 1. 원칙 (N1~N8, 잴 수 있게)

| # | 원칙 | 측정 기준 |
|---|---|---|
| N1 | 화면마다 주인공 하나 | 장면을 다루는 화면은 첫 화면(폰 390×844, PC 1440×900)에서 작전판이 가장 큰 요소이고, 넓이의 30% 이상(PC는 콘텐츠 영역 기준) |
| N2 | 주 버튼 하나, 카드 안 카드 0 | 화면(또는 PC의 한 단)당 꽉 찬 버튼 1개. 나머지는 글자 버튼·글자 링크 |
| N3 | 글자 5단계 | 13 · 17 · 22 · 30 · 48(숫자 하나). 본문 17px. 12px 이하는 쓰지 않는다(법적 고지 13px) |
| N4 | 강조색 하나 | 형광 노랑은 판 위 원 1개와 오답 띠에만. 진영 파랑·빨강, 이득 금색·손해 회색은 정보 색으로 장면과 손익 줄에서만 |
| N5 | 판정은 대상에 붙인다 | 'Q 없음' 타일은 그 챔피언 자석 옆, '확인됨·아마도'는 그 값 옆. 범례 0 |
| N6 | 숫자 대신 신호, 말은 한 번 | 본문에 초·거리·골드·퍼센트·표본 0. 그림 → 제목 → 본문이 같은 말을 하지 않는다(본문 한 문장). 용어 풀이는 밑줄 낱말을 누르면 뜨는 한 줄 |
| N7 | 원은 실제 비율, 통째로 | 반지름 = 평타 사거리 × 판 축척 k(케이틀린 650 · 아리 550 · 신드라 550 · 징크스 525 · 쓰레쉬 450). 핵심 원은 판 안에 100% |
| N8 | 그림 한 벌, 움직임 한 곳 | 작전판 키트 하나로 모든 장면을 그린다. 화면당 움직이는 곳 1곳. 흐림·빛 번짐·광택 0. `prefers-reduced-motion`이면 움직임 0 |

### 2.1 색

| 토큰 | 라이트 | 다크(시스템 다크) | 쓰는 곳 |
|---|---|---|---|
| `--paper` | `#FFFFFF` | `#1C1D20` 흑연 | 화면 바탕, 레일·탭 |
| `--ink` | `#16171A` | `#F1F1EF` | 글, 아이콘, 주 버튼 면(다크에서는 밝은 면) |
| `--ink-2` | `#5A5D65` | `#A9ACB3` | 날짜·메타 한 줄. 글자의 15% 이하 |
| `--line` | `#E3E4DF` | `#34363B` | 구분선 한 줄(절 머리 띠로 쓰지 않음) |
| `--board` | `#F3F4F0` | `#F3F4F0` (그대로) | 작전판, 규칙 메모, 풀이 한 줄, 시트 속 표 바탕 = '밝은 물건' |
| `--hi` 형광펜 | `#FFE34A` | `#FFE34A` (그대로) | 판 위 '그 순간' 원, 오답 띠(`--hi` 45% + 종이 = `#FFF2AE`) |

- **밝은 물건 규칙**: `--board` 위의 글과 선은 다크에서도 `#16171A`(고정 잉크)로 쓴다. 다크 모드는 틀만 흑연으로 바뀌고 판은 그대로다.
- **정보 색**(장면과 손익 줄에서만): 우리 편 `#2E66E0` · 상대 `#DE3F3B`(글자로 쓸 때 `#C7302C`) · 이득 미니언 `#F0BE00` · 손해 미니언 `#B7BAC0` · 깎인 체력 `#F2A29E` · 다크에서 파랑 글자 `#7FA6FF`.
- 그림 전용 인쇄색(판 키트 안에서만): 라인 `#EBEAE3`, 강 `#DCE8EF`, 정글 벽 `#E5E6E0`, 벽 선 `#CDD0C8`, 점 격자 `#D9DBD4`.

## 3. 배치

| 폭 | 내비게이션 | 화면 짜임 |
|---|---|---|
| PC ≥ 1024px (MVP 기준 1440) | 왼쪽 레일 232px: 워드마크(GRIMOIRE / 그리모어 / 롤 복기 작전판) + 5항목(오늘 · 복기 · 교과서 · 연습 · 나) | 콘텐츠 최대 1180px. 화면마다 '큰 작전판 + 오른쪽 글 단' 2단(7:5, 오늘·정석은 8:4). 폰을 늘린 1단을 쓰지 않는다 |
| 태블릿 768~1023 | 아래 탭(폰과 같음) | 1단, 판 폭 100% |
| 폰 < 768 | 아래 탭 5개(라벨 13px) | 1단. 복기는 판 → 판정 제목 → 본문 → 컷 막대 순으로 다시 쌓아 첫 844px 안에 판정까지 보이게 한다 |

- 정석은 탭이 아니라 교과서 안 글자 탭(레슨 / 정석)이다(copy-v2 1.0).
- 시연용 상태 전환(S1~S16)과 '예시 데이터' 안내는 앱 틀 바깥 맨 위 시연 막대 한 곳(고르기 상자 하나)에만 둔다. 화면 안에는 시연 해설을 쓰지 않는다(T05).

## 4. 화면별 주인공

## 5. 부품 규칙

| 부품 | 규칙 |
|---|---|
| 주 버튼 | 높이 56, 반경 12, 잉크 면 + 흰 글자 17/800. 다크는 밝은 면 + 잉크 글자. 화면(또는 PC 한 단)당 1개 |
| 글자 버튼 | 17 또는 13/800, 잉크, 밑줄 없음. 링크는 밑줄 |
| 전환(실제 / 이렇게 했다면) | 글자 두 개 + 고른 쪽 아래 3px 잉크 줄. 알약 상자 쓰지 않음 |
| 컷 막대 | 1~6 칸(4px 막대) + ◀ ▶ 대신 잉크 화살표 아이콘 버튼 2개 + "3 / 6" 13px |
| 확인됨 · 아마도 | 13/700, 채운 점 · 빈 점 + 낱말. 그 값 바로 옆 |
| 체력바 | 높이 11, 1.6px 잉크 테두리, 진영색 채움, 깎인 칸 `#F2A29E`, 10칸 눈금, 직각. 옆에 '많이 깎임·조금·그대로' 13px |
| 손익 줄 | "미니언 약 [48px 숫자]마리 값 손해/이득" + 미니언 자석 n개(잉크 테두리) |
| 규칙 메모 | `--board` 면, 반경 12, "다음 판에 볼 것" 13/800 + 규칙 17px. 화살표는 마커 그림 |
| 언제 → 무엇을 → 왜 | 세 줄. 라벨 13/800 왼쪽 52px, '무엇을'만 22/900. 상자 없음, 줄 사이 `--line` |
| 풀이 한 줄 | 밑줄(점선 2px) 낱말을 누르면 바로 아래 `--board` 한 줄이 열린다. 다시 누르면 닫힘 |
| 자세히 보기 시트 | 화면 아래(폰) / 오른쪽(PC)에서 열리는 한 겹. 숫자·근거·패치·표본은 여기에만. 닫기 버튼 + Esc. 시트 안에 시트 없음 |
| 틀렸어요 (이의 4택) | 복기 머리 오른쪽 글자 버튼 → 시트에 4택: 안 물러났어요 · 이유가 있었어요 · 이 매치업은 달라요 · 그림이 실제와 달라요 → 고르면 "이 장면을 숨겼어요." + ‹되돌리기› |
| 정답·오답 띠 | 화면 아래 띠 1개 + 버튼 1개. 오답 = 오답 띠 노랑 + "이렇게 해 봐요" + 다음 행동 한 줄. 정답 = 잉크 띠 + "맞아요". 빨강 X 없음 |

## 7. 모션

- 원칙: **"자석은 딱, 형광펜은 쓱."**
- 자석이 새 자리로 가면 0.16초 안에 붙는다(살짝 넘었다 돌아오는 곡선).
- 그 순간의 원은 0.55초 동안 한 번 칠해진다.
- 정답 띠가 열릴 때 판 위 원이 한 번 더 칠해진다. 화면당 연출은 이것 하나다.
- 반응 연습은 움직임 자체가 문제다. 줄인 움직임 설정이면 장면을 0.5초 단위 정지 컷으로 넘긴다.
- 시트는 0.2초 안에 열리고, 흐림 없이 뒤를 40% 어둡게 한다.

## 8. 말투

- 토스 문법을 따른다. 해요체, 능동문, 버튼 2~6자('~하기' 대신 '연습 시작'처럼 명사 + 동사), '취소' 대신 '닫기'.
- 숫자는 생활 단위 하나만 쓴다("미니언 약 5마리 값").
- 샘플: "여기 한 칸이 아까웠어요. 신드라 Q가 회색이었거든요." / "다음 판엔 이것 하나만 봐요. 회색 Q, 그리고 내 원." / "맞아요. 막타 치러 온 순간이 제일 약해요."
- 판타지 말은 쓰지 않는다: 마도서·해독·시전·각인·현자·견습. 대체어는 `copy-v2.md` 4절: 교과서, 연습, 기술 하나, 오늘 연습, 다음 판 확인 · 숙련 아직/알아요/해 봤어요/몸에 익음 · 요금제 무료/코치/코치 정밀.
- 화면 글에 가운데점·괄호 풀이 0(copy-v2 규칙 5). 메타 한 줄은 칸 띄우기로 나눈다. 버튼은 띄어쓰기를 빼고 2~6자(연습하기, 다시 풀기, 이어 읽기, 문제 풀기, 목표로 정하기, 다음 연습 받기).

## 9. 접근성

- 대비는 2.2절 표 그대로 AA 통과. 색 단독 금지는 2.3절.
- 모든 상호작용은 `<button>`·`<a>`이고, 키보드 포커스는 3px 잉크(다크는 밝은) 테두리로 보인다.
- 작전판 끌기는 판에 포커스를 두고 좌우 화살표 키로도 된다. 컷 재생은 이전·다음 버튼과 1~6 칸 버튼.
- 작전판 SVG마다 `role="img"`와 지금 컷을 한 문장으로 쓴 `aria-label`을 단다(컷이 바뀌면 갱신).
- 띠와 시트 결과는 `role="status"`로 읽힌다. 시트는 열 때 포커스를 옮기고 닫으면 되돌린다.
- 터치 목표 44px 이상. `prefers-reduced-motion`이면 형광펜·자석 움직임 0, 반응 연습은 정지 컷.
