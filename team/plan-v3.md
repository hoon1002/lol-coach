## 1. 제품 재정의

### 1.1 한 줄 정의와 이름

| 대상 | 문장 |
|---|---|
| 사용자에게 | "롤이 어떤 게임인지, 왜 그렇게 해야 하는지, 움직이는 그림으로 하나씩 보여 주는 롤 교과서" |
| 팀 내부 | "개념 하나를 장면 하나로 보여 주고, 개념 사이의 '왜'를 연결해 순서대로 가르치는 시각 교과서" |

- 이름은 **GRIMOIRE(그리모어)**를 유지한다. A안 부제 "롤 복기 작전판"은 복기 기능을 미루면서 맞지 않게 됐다. 새 부제는 **"움직이는 롤 교과서" [가안]**으로 둔다. 부제의 '롤'(LoL의 한국어 통칭)이 Riot 상표 사용 제한에 걸리는지는 상표 조사에서 함께 본다(research.md B-6, 7장 K6).
- 사용자가 고른 A 작전판의 **그림 언어**(위에서 본 협곡, 진영색 자석, 평타 사거리 원, 형광펜 원 하나)는 살린다. 다만 화면 전체의 인상은 파티클 모션으로 바뀐다. 둘의 역할 나눔은 2.3.

### 1.2 대상: 처음 하는 사람부터 골드까지 (판단)

**판단: 포함한다.** 사용자 원문이 "롤이 어떤게임인지 상대 넥서스를 부수는 게임인데…"에서 시작하므로 롤을 처음 하는 사람이 빠지면 요청과 어긋난다. 반대로 플래 이상까지 1차 대상에 넣으면 기본 개념 설명이 지루해지고 화면 말투가 갈린다.

| 구분 | 누구 | 이 사람이 원하는 것 | 우리가 주는 첫 가치 | 깊이 |
|---|---|---|---|---|
| A. 처음 하는 사람 (1차) | 친구 따라 시작했거나 튜토리얼만 끝낸 사람, 롤을 해 본 적은 없지만 LCK·친구 방송을 보는 사람 | "도대체 뭘 해야 이기는지" | 0장: 넥서스·라인·미니언·포탑·골드가 짧은 장면으로 한 번에 보임 | 기본 |
| B. 아이언~골드 (1차) | 1~3년 했지만 왜 지는지 모르는 사람(기존 P1) | "라인전·정글·오브젝트를 제대로" | 라인전·상성·에픽 몬스터의 '왜' | 기본 + 심화 |
| C. 관전자 (보조) [가설] | LCK를 보는데 해설이 무슨 말인지 모르는 사람 | "해설 용어와 운영을 알아듣고 싶다" | 5장 에픽 몬스터, 6장 운영 | 기본 |
| D. 플래 이상 (V1 이후) | 정체된 중수(기존 P2) | 심화 운영·한타 | 심화 개념 확대 | 심화 |

- **말투는 A에 맞춘다.** B가 지루하지 않게, 개념 페이지 첫 화면에 "아는 개념이면 건너뛰기"와 확인 문제 먼저 풀기(맞히면 건너뜀)를 둔다.
- 결정은 사용자 확인을 받는다(D2).

### 1.3 핵심 약속

1. **보여 주고 나서 말한다.** 모든 개념은 장면이 먼저다. 글은 장면이 끝난 그림을 짚는 데만 쓴다.
2. **"왜"까지 간다.** "드래곤을 먹어라"가 아니라 "드래곤을 먹으면 무엇이 쌓이고, 그래서 왜 한타가 쉬워지는지"까지 이어 준다.
3. **순서가 있다.** 무엇을 먼저 알아야 하는지 개념 지도에 표시하고, 개념마다 다음 개념을 알려 준다.
4. **숫자 대신 눈에 보이는 신호.** "쿨다운 7초" 대신 "스킬 아이콘이 회색일 때"(feedback-2026-11-03 리더 결정 3). 숫자는 '자세히'에만 둔다.
5. **패치로 낡지 않는다.** 원리와 수치를 나눠 저장하고, 수치가 바뀌면 그 개념에 바로 반영한다(5.2).

### 1.4 하지 않는 것

| 하지 않음 | 이유 |
|---|---|
| 한 판 분석·복기·정밀 분석·컴패니언 | 사용자가 "너무 고급"이라고 했다. V2 이후로 미루고 `plan.md`를 참고용으로 남긴다 |
| 티어 리스트·빌드 추천·룬 추천 | 전적 사이트가 이미 한다. 정석을 단정하는 추천은 Riot의 '결정 지시 금지'와도 맞지 않는다(research.md B-4) |
| 게임 중 기능(오버레이·음성) | 정책상 금지 쪽(research.md B-4) |
| "필승법", "N일이면 골드" 약속 | 거짓 약속. brief의 신뢰 원칙 |
| 개념을 보여 주지 않는 장식 모션 | 화려함이 학습을 방해할 수 있다(7장 K2). 모든 모션은 개념 하나를 보여 줘야 한다 |
| Riot 시네마틱·클라이언트 화면을 닮은 연출 | 개발자 정책상 Riot 제품과 비슷한 스타일 금지(research.md B-6, 7장 K5) |
| MMR처럼 보이는 점수·티어 예측 | 정책상 금지(research.md B-4). 진행 기록은 개념 단위로만 |

### 2.3 개념 페이지 흐름

**레슨과 개념 페이지의 관계**: 레슨 하나는 컷 여러 개로 이어지고, **컷 하나 = 개념 하나의 장면**이다. 컷마다 개념 ID(`C{장}.{nn}`)가 붙어 있다(→ curriculum-v3.md 샘플 레슨). 레슨은 개념 여러 개를 한 흐름으로 보는 길이고, 개념 페이지는 그 개념의 컷을 잘라 ① 장면으로 쓴다. 그래서 장면은 한 번 만들면 레슨과 개념 페이지 양쪽에 쓰인다.

```
① 모션 장면 (10~40초) → ② 쉬운 설명 (멈춘 그림 위) → ③ 확인 문제 (1~2개) → ④ 이어지는 개념 (2~3개)
                                                             └ ⑤ 더 깊이 (심화) · 자세히 (숫자·패치)
```

| 단계 | 화면 | 규칙 |
|---|---|---|
| ① 모션 장면 | 레슨에서 이 개념의 컷을 잘라 쓴다. 세로 화면 가득. 가루(파티클)가 흩어진 상태에서 모여 협곡의 한 장면이 되고, 핵심 순간에 다시 쪼개졌다 합쳐지며 무엇이 바뀌는지 보여 준다. 예: 용이 부서진 힘 가루가 다섯 갈래로 나뉘어 우리 팀에게 스며든다. 가루는 게임 안에서 실제로 옮겨 가는 것(골드·경험치·진영의 힘·시야·안개·에픽 몬스터 강화, 6종)만 나타낸다(→ curriculum-v3.md 1절 '가루 문법') | 장면 하나에 개념 하나. 화면 글은 한 줄 이하. 탭하면 멈춤·다시. 소리는 기본 꺼짐 [가안] |
| ② 쉬운 설명 | 장면의 마지막 프레임이 **멈춘 작전판 그림**이 되고, 그 위에 형광펜 원 하나 + 손글씨 2곳까지(copy-v2 규칙 9). 아래 글은 개념 종류에 따라 둘로 나뉜다. **행동 개념**(딜교 타이밍, 귀환 시점처럼 게임에서 할 일): "언제(눈에 보이는 신호) → 무엇을 → 왜(한 줄)" 세 문장. **사실 개념**(넥서스, 에픽 몬스터 종류처럼 알아야 할 것): "한 줄 정의 + 왜 중요한가" | plain-language.md 0절 규칙. 숫자는 쓰지 않는다. 개념 종류는 curriculum-v3.md가 개념마다 정한다 |
| ③ 확인 문제 | 그림 문제 1~2개(2×2 그림 보기, "앞으로? 뒤로?"). 맞히면 짧은 모션 한 번, 틀리면 장면의 그 순간으로 돌아가 다시 보여 줌 | 문제는 개념마다 3~5개 풀에서 돌림 |
| ④ 이어지는 개념 | "이걸 알면 다음은" 카드 2~3개. 각 카드는 연결 이유 한 줄(예: "드래곤을 먹으면 → 왜 한타가 쉬워지나") | 2.4 연결 종류 표시 |
| ⑤ 더 깊이 · 자세히 | 더 깊이 = 이어지는 심화 개념. 자세히 = 실제 수치, 확인한 패치, 출처 | 자세히의 수치는 Fact Store에서 자동(5.2) |

- **역할 나눔**: 파티클 모션은 "무엇이 일어나고 무엇이 쌓이는지"를 보여 주는 **움직이는 층**, 작전판 그림은 "어디를 봐야 하는지"를 짚는 **멈춘 층**이다. 가루가 모여 작전판이 되므로 두 층이 한 흐름으로 이어진다.
- 모션 줄이기(`prefers-reduced-motion` 또는 앱 설정)를 켜면 ①은 파티클 없이 **전·후 정지 그림 두 장 + 화살표 하나**로 바꾼다(curriculum-v3.md 1절, 7장 K3).

### 2.4 개념 사이 연결

| 연결 종류 | 뜻 | 예 | 화면 표시 |
|---|---|---|---|
| 먼저 알기 | 이 개념을 이해하려면 먼저 필요한 개념 | 막타 → 골드 | 개념 페이지 맨 위 "먼저 보면 좋아요" 1~2개 |
| 다음으로 | 이어서 배우면 좋은 개념 | 웨이브 → 프리징 | ④ 이어지는 개념 |
| 왜 이어지나 | 원인과 결과로 묶인 개념 | 에픽 몬스터 → 골드·버프 → 운영 → 한타 | ④ 카드의 연결 이유 한 줄 + 개념 지도에서 가루가 선을 따라 흐르는 모션 |

- 개념 지도 화면에서 개념 하나를 누르면 그 개념의 '왜 이어지나' 선만 밝아지고 가루가 그 선을 따라 흐른다. 개념 연결 그 자체를 보여 주는 모션이라 장식이 아니다.
- 연결 데이터(개념 ID 쌍 + 종류 + 이유 한 줄)는 curriculum-v3.md가 정본이다.

### 4.3 성공 지표 (WVI 대신)

**북극성: 주간 기억된 개념 수** = 그 주에 '기억해요'(며칠 뒤 복습 문제를 다시 맞힘)로 바뀐 (사용자 × 개념) 쌍의 수.
- 이유: 장면 조회 수나 체류 시간은 화려한 모션 때문에 쉽게 부풀지만 학습을 말해 주지 않는다. 며칠 뒤에도 맞히는지는 "봤다"가 아니라 "배웠다"에 가깝다(체스닷컴·듀오링고처럼 다시 꺼내 보는 연습을 중심에 둠, research.md E-3·E-4).
- 한계: 우리 문제를 맞히는 것이 게임에서 쓰는 것과 같지는 않다. 그래서 보조로 "다음 판에 써 봤어요" 자기 응답을 받고, V2에서 실제 게임 지표로 확인한다.

| 층 | 지표 | 정의 | MVP 목표 [가설] |
|---|---|---|---|
| 활성화 | 첫 장면 완주율 | 첫 개념 장면을 끝까지 본 비율 | 70% |
| 활성화 | 첫 세션 개념 수 | 첫 방문에 '알아요'가 된 개념 수 | 중앙값 2개 |
| 학습 | 첫 시도 정답률 | 확인 문제를 처음에 맞힌 비율 | 60~85% (넘으면 너무 쉬움, 모자라면 설명 실패 → 개념별로 고침) |
| 학습 | 기억 유지율 | '알아요' 개념 중 7일 뒤 복습에서 다시 맞힌 비율 | 60% |
| 학습 | 연결 따라가기 | ④ 이어지는 개념을 누른 비율 | 40% |
| 실전 (보조) | "다음 판에 써 봤어요" | 개념 페이지 재방문 때 묻는 한 문항 | 측정 후 설정 |
| 리텐션 | W1 / W4 | 그 주에 개념 1개 이상 보거나 복습함 | 40% / 20% |
| 콘텐츠 | 검색 실패율 | 결과 0개 검색 비율 | 10% 미만 |
| 품질 | 장면 끊김 | 기준 기기에서 프레임이 떨어진 장면 비율 | 0개 장면 |
| 품질 | 모션 줄이기 사용률 | 설정을 켠 사용자 비율 | 추적(높으면 멀미·성능 문제 신호) |
| 신뢰 | 패치 노후 개념 수 | 패치 후 7일이 지나도록 수치를 재확인하지 않은 개념 | 0개 |

### 4.4 수익 모델 재검토와 Riot 정책

**정책에서 확인한 것** (2026-11-04, Riot "Legal Jibber Jabber" 팬 콘텐츠 정책 요약 + research.md B-3):
- 팬 프로젝트는 원칙적으로 **무료**이고, 서면 라이선스 없이 **유료 장벽(paywall)을 둘 수 없다**. 광고는 Riot이 보기에 적절한 범위에서 허용된다.
- **앱에서 Riot IP를 쓰는 것은 금지**이고, Apple·Google 스토어 출시에는 **서면 라이선스 또는 유효한 Riot API 키**가 필요하다. 상업 프로젝트도 API 약관을 지키고 유효한 API 키를 써야 한다.
- API 제품으로 등록하면 개발자 정책이 적용된다: **무료 등급 의무**, 유료는 **변형적**(새 정보·통찰)이어야 하고, Approved·Acknowledged 상태에서만 과금(research.md B-3).

**그래서 기획 결정**:
1. GRIMOIRE는 개념 앱이라도 **Riot API 제품으로 등록**한다. API는 RSO 계정 연결과 "자주 하는 챔피언·포지션 기준 추천"(2.5)에 실제로 쓴다. API 사용이 형식적으로 보이면 심사에서 문제가 될 수 있어 DevRel에 확인한다 [정책 확인 필요].
2. **기본 개념은 전부 무료**(정책상 무료 등급 + 입문자가 막히면 안 됨 + 검색 유입).
3. 유료 후보는 우리가 새로 만든 **심화 설명·장면**(변형적 콘텐츠)에만 붙인다. 형태는 D1에서 정한다.

| 안 | 무료 | 유료 | 장점 | 단점 |
|---|---|---|---|---|
| (a) 심화 하루 1개 무료 + 구독 **[추천]** | 기본 전부, 심화 하루 1개, 복습 | 심화 무제한, 오프라인 저장, 광고 없음 | 체스닷컴 레슨 방식(무료는 하루 1개, research.md E-3). 배우는 흐름은 막지 않음 | 심화 제작량이 충분해야 의미가 있음 |
| (b) 전부 무료 + 광고 | 전부 | — | 정책 위험 가장 낮음, 유입 최대 | 광고가 모션 몰입과 학습을 깨뜨림. 광고 단가 근거 없음 |
| (c) 전부 무료, 돈은 V2 분석에서 | 전부 | V2 분석 기능 | 지금은 학습 검증에만 집중 | V2까지 수익 0 |

- 가격 가설: (a)의 구독은 **월 3,900~4,900원** [가설]. 개인 분석이 없으므로 YOUR.GG(월 7,900원~)보다 낮게, 체스닷컴 KR Gold(월 4,834원, 연간 결제 월 환산)·Skill Capped(월 $8.25부터) 근처로 본다(research.md A-1·E-3). 랜딩 가격 테스트로 정한다.
- 원가는 경기 분석이 없어 LLM 비용이 거의 없다. 비용의 대부분은 **콘텐츠·모션 제작 인건비**다(5장).

- **부품 라이브러리 [가안]**: curriculum-v3.md 1절의 가루 6종 × 움직임 4가지(쪼개짐·모임·흐름·퍼짐)를 기본 부품으로 삼고, 그 위에 골드 흐름, 경험치 흐름, 미니언 웨이브 행진, 포탑 사격, 평타 사거리 원 펼치기, 스킬 아이콘 회색 전환, 체력바 줄기, 에픽 몬스터 처치 → 팀에게 버프가 흘러가기, 와드 시야 번짐, 마커 화살표·발자국 그리기, 형광펜 원 칠하기. 12~15개를 먼저 만들고, 첫 20개 장면 뒤에는 모션 시간이 약 35% 준다고 본다 [가설].
- **기술 [가안, → 모션 디렉터 문서]**: 벡터 상태 기계 애니메이션(예: Rive)을 기본으로 하고, 가루가 아주 많은 장면만 WebGL로 그린다. 한 비교 글은 같은 애니메이션이 Lottie 약 17fps, Rive 약 60fps였다고 보고했지만, 파티클 전용 시험이 아니라서 방향 참고로만 쓴다. 우리 기준 기기에서 직접 잰다(Phase 0).
- **인력 (MVP) [가설]**: PM 1 · 교과서 설계·집필 2 · 모션 디렉터 1 · 모션 디자이너 2 · 프론트엔드 2(장면 플레이어·성능) · 백엔드 0.5 · UI 디자인 1 · QA 0.5 = 사내 10명. 도메인 감수는 외부 시간제(개념당 1~1.5시간). 1인 월 600만 원(급여·4대보험·간접비, plan.md 8.6과 같은 가정)이면 월 약 ₩6,000만, Phase 0 + MVP 4개월이면 약 ₩2.4억이다.
- **도구·인프라**: 모션 도구 라이선스와 그림 파일 전송비는 작다고 보지만 값은 조사가 필요하다 → 조사원. 경기 분석이 없어서 LLM·분석 서버 비용은 거의 없다.

**구독만으로 손익을 맞추려면 [가설]** (순수입 = 가격 ÷ 1.1 × 0.97, 인건비만 계산)

| 팀 규모 | 월 3,900원 | 월 4,900원 |
|---|---|---|
| V1 12명(월 ₩7,200만) | 유료 약 2.1만 명 → 전환 2%면 MAU 약 105만, 5%면 약 42만 | 유료 약 1.7만 명 → MAU 약 83만 / 33만 |
| 제작 후 유지 5명(월 ₩3,000만) | 유료 약 8,700명 → MAU 약 44만 / 17만 | 유료 약 6,900명 → MAU 약 35만 / 14만 |

- KR LoL 이용자 수는 공식 수치가 없다(research.md E-1). 그래서 결론은 이렇다: **콘텐츠를 많이 만드는 동안에는 구독만으로 맞추기 어렵다.** 제작이 끝난 뒤 유지 팀으로 줄이고, B2B(학교 e스포츠 동아리·아카데미), V2 분석 상품으로 보완한다. 전환율 참고치는 체스닷컴 약 0.75%, 듀오링고 약 9%다(research.md E-3·E-4).

### 5.2 패치마다 바뀌는 수치와 콘텐츠 갱신

LoL은 약 2주마다 패치된다. 개념의 대부분(넥서스를 부순다, 막타가 골드다, 드래곤을 먹으면 팀이 강해진다)은 바뀌지 않지만 수치·아이템·오브젝트 보상·시즌 시스템은 바뀐다(예: 26.01 아타칸 삭제, research.md D-2).

| 규칙 | 내용 | 갱신 비용을 줄이는 이유 |
|---|---|---|
| 장면에 숫자를 그려 넣지 않는다 | 화면 본문·장면은 신호만(회색 아이콘, 사거리 원). 숫자는 '자세히' 글 층에만 | 수치가 바뀌어도 장면을 다시 만들 필요가 없다 |
| 장면 크기 값은 데이터로 | 사거리 원 반지름 같은 비율은 Data Dragon 값에서 자동으로 정한다 [가안] | 사거리 패치 때 자동 반영 |
| 수치 저장소(Fact Store) | Data Dragon 자동 값 + 편집자가 확인한 값(오브젝트 보상 등, 출발점은 조사원의 `facts-v3.md`), 값마다 패치 태그 | 값이 바뀐 개념 목록이 자동으로 나온다 |
| 개념마다 "확인한 패치" | 패치 뒤 7일 안에 다시 확인하지 않으면 개념에 "이번 패치 확인 중" 표시 | 낡은 내용을 숨기지 않는다 |

| 갱신 종류 | 빈도 | 비용 [가설] |
|---|---|---|
| 일반 패치 점검 | 약 2주마다 | 편집자 4~8시간(값 바뀐 개념 확인, 자세히 갱신, 패치 브리핑 V1) |
| 시즌 대개편 | 연 1~2회 | 영향받는 장면 10~20% 재제작 → 83개 기준 약 120~430시간 |

## 6. 경쟁과 차별점

| 경쟁 | 사용자가 거기서 얻는 것 | 한계 | 우리 대응 |
|---|---|---|---|
| YouTube 강의·쇼츠 | 재미, 깊은 해설, 무료. 쇼츠는 짧고 화려함 | 흩어져 있고 순서가 없다. 패치 지난 영상이 섞인다. 강사마다 말이 다르다. 배웠는지 확인할 방법이 없다 | 순서 있는 교과서 + 확인 문제 + 패치 태그. 쇼츠는 경쟁이자 유입 통로(공유용 15초 장면, C-09) |
| 나무위키 | 정보량이 가장 많고 검색이 쉬움 | 글 위주로 빽빽하다. 입문자에게 순서와 그림이 없다. 편집에 따라 질이 다르다 | 장면 먼저, 쉬운 말. 정보량으로 겨루지 않는다 |
| 전적 사이트 가이드 (OP.GG·DeepLoL 등) | 빌드·룬·티어, "무엇을 고를까" | "왜"를 가르치지 않는다 | 우리는 왜. 빌드·티어는 다루지 않는다(1.4) |
| YOUR.GG | 내 판 AI 코칭, 영상 장면 해설(research.md A-2) | 교과서(순서 있는 개념 학습)가 확인되지 않음 | 이번 단계에서 우리는 분석을 하지 않아 직접 겹침이 줄었다. 그쪽이 개념 콘텐츠를 붙이면 경쟁이 된다 → 개념 연결과 기억 확인으로 차별 |
| Riot 공식 튜토리얼·입문 안내 | 조작과 아주 기초 | 깊이가 얕다 [범위 확인 필요 → 조사원] | 0장은 겹치지만 "왜"와 다음 개념 연결로 넘어간다 |
| Skill Capped 등 영어 강의 구독 | 체계적인 영상 강의(월 $8.25부터, research.md A-1) | 영어, 긴 영상 | 한국어, 세로 짧은 장면 |
| 롤백과사전 (iOS 앱) | 커뮤니티 정보·팁 모음, 입문자용 기초 소개 | 평점 1개, 최신 업데이트 여부 확인 안 됨(App Store, 2026-11-04 확인) | 이 범주의 앱이 비어 있다는 신호로 본다 [가설] |

**차별점 (무게중심 순서)**
1. **순서가 있는 교과서**: 무엇을 먼저 알아야 하는지가 개념 지도에 있다.
2. **개념 사이의 "왜" 연결**: 에픽 몬스터 → 골드·버프 → 운영 → 한타처럼 원인과 결과를 따라간다.
3. **기억 확인**: 며칠 뒤 다시 묻는다. 영상과 위키에는 없다.
4. **보여 주고 나서 말한다**: 가루가 모여 장면이 되고, 장면이 멈추면 짚어 주는 그림이 된다.
5. **숫자 대신 신호, 일반 유저 말투**, 그리고 패치로 낡지 않는 구조.

- 화려한 모션 자체는 남이 쉽게 따라 할 수 있다. 모션은 **첫인상과 공유**를 맡고, 차별의 무게는 1~3에 둔다.
