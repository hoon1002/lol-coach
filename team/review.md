### 1.2 가장 강한 점 3개

1. **원자 = 지표 = 카드 = 드릴의 1:1 설계가 실제로 맞물린다.** 엔진 임시 ID 28개가 curriculum g표에 빠짐없이 대응되고, 프로토타입·design의 원자 ID 56개가 모두 정본 233개 안에 있다(스크립트 대조). 경쟁사와 갈리는 '닫힌 루프'의 뼈대가 문서로 성립한다.
2. **정직한 해상도 설계.** R0~R4 등급, "R2 카드는 행동 단정 금지"(plan RC-03 ②), 관측(−180, −96G)과 추정(+67G)을 섞지 않는 카드 문법(engine 7.4 ⑪), 판단 보류(abstain), 실선=관측·점선=추정 시각 문법(design 0장). "백무빙"을 API로 할 수 없다는 사실을 숨기지 않았다.
3. **사실 기반 시즌 반영.** 26.01 템포 변경(첫 미니언 0:30, 캠프 0:55, 바론 20:00, 방패 14:00 유지, 아타칸 삭제), 26.09 역할 퀘스트·WASD, 26.10 어그로, 26.21 리플레이 제한까지 반영했고, 리뷰어가 표본 확인한 게임 수치·규칙 12항목(1.4절)에서 틀린 값은 없었고, 미확정이던 값 1건(미니언 피해 배율, R-19)과 불완전한 규칙 1건(포탑 아래 원거리 막타, R-20)만 나왔다.

### 1.3 가장 큰 위험 3개

1. **MVP 측정의 실체가 약하다.** MVP 원자 20개 중 와드 위치·살아남은 교전·웨이브 상태를 전제한 원자가 섞여 있고(R-01·R-02), 엔진 MVP 탐지기 목록과도 어긋난다. MVP의 단 하나의 검증 질문("처방한 원자가 실제로 개선되는가", plan 7.1)이 노이즈에 묻힐 수 있다.
2. **제품의 정점(초 단위 피드백·미시 정석)이 아직 검증되지 않은 두 가정 위에 있다.** ① Replay API 자동 렌더 + CV 정확도(POC 전) ② 마스터+ 기여자 수천 명 모집 + Riot의 기여 프로그램 승인(미확인). 둘 중 하나라도 막히면 사용자 원문의 핵심 예시가 사람 코치 서비스로 남는다(R-07·R-08·R-25).
3. **돈과 사람 계산이 없다.** 엔진 원가 MAU당 $0.2~0.4에 월 7,900원이면 인건비를 빼고도 유료 전환 4~8%가 필요한데[리뷰어 계산], 참고 사례는 체스닷컴 0.75%·듀오링고 9%다(research E). 원자 233개 제작에 약 1,900~2,700시간이 드는데 계획된 콘텐츠 인력은 2명이다(R-06·R-10).
